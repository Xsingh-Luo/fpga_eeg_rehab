# 归因实验纪律

> 类型：**提示词工作流 + 检查清单**
> 验证状态：✅ 受控测出 +2.94 pp；两次差点误判方法无效

---

## 1. 适用场景

- 你要报「我做了 X 改进，准确率提升了 Y 个点」
- 你要在论文/比赛里写消融实验
- 你测出来的结果**和文献严重不符**，不知道是自己错了还是方法不行

**不适用**：纯工程集成（只是把现成模块拼起来）；或改进项之间强耦合、无法分离。

---

## 2. 三条硬纪律

### 纪律 1：同管线受控对比，只变一个因素

**A/B 对比必须在同一条代码路径上跑**，只允许一个变量不同。

跨管线（MATLAB vs Python、CPU vs GPU）**只比趋势，不比绝对值**。

> 本项目的代价：早期用 MATLAB 和 Python 各自实现，FBCSP 增益一个报 +3.01 pp、
> 一个报 +0.29 pp。追查很久才发现是 Python 侧一个**下标写错**。
> 在此之前的所有"管线差异分析"都是白做的。

### 纪律 2：消除信息泄漏 —— 训练集统计量绝不能在测试集上算

**每一处"在训练集上拟合"的东西，都要检查它是否真的只用训练集。**

本项目的泄漏检查清单（几乎适用于所有机器学习流水线）：

| 环节 | 必须只用训练集 | 常见错误 |
|---|---|---|
| 空间滤波器（CSP / PCA） | ✅ | 在全量数据上 fit 再交叉验证 |
| 特征选择 | ✅ | 先选完特征再分折 |
| 标准化（均值/方差） | ✅ | 用全量数据算 mean/std |
| 归一化系数 | ✅ | 同上 |
| 超参数 | ✅ | 用测试集挑超参 |

**四道防泄漏的落地写法**：

```python
W      = csp_fit(X_train, y_train)          # ① 滤波器只在训练集拟合
F_tr   = features(X_train, W)
F_te   = features(X_test,  W)               # ② 测试集用同一个 W
idx    = mibif_select(F_tr, y_train)        # ③ 特征选择只看训练集
mu, sd = F_tr.mean(0), F_tr.std(0)          # ④ 标准化统计量只看训练集
```

### 纪律 3：消除效应必须能分离

改进点之间有重叠时，用 **2×2 消融**把增益归因清楚。

本项目实例（特征 × 分类器）：

| 特征组 | 线性 SVM | NBPW | 结论 |
|---|---|---|---|
| 单带（基线） | 74.39% | 74.37% | — |
| FBCSP | 77.40% | 77.88% | 特征贡献 ≈ +3.0 |
| **差异** | **+3.01** | **+3.51** | **换分类器贡献 ≈ +0.02 ~ +0.48** |

**结论：增益几乎全部来自特征，不来自分类器。**
如果没有这张 2×2 表，就很容易误以为是"我换了更好的分类器"。

## 3. 提示词模板

### 模板 A：设计消融

```
我有一个改进点 X，想证明它带来了 Y 的提升。请帮我设计消融实验：
1. 需要哪几组对照，才能把 X 的贡献单独分离出来？
2. 哪些统计量必须在训练集内计算（列出所有可能的泄漏点）？
3. 用什么指标（准确率 / kappa / 其他）？为什么？
4. 如果改进项之间可能相互干扰，怎么设计组合实验？
```

### 模板 B：结果与文献矛盾

```
我的实测结果是 <数字>，文献报告的是 <数字>，差距很大。
请按以下顺序排查，不要先下"方法不行"的结论：
1. 实验设计是否与文献一致（校准/训练/测试的划分方式）
2. 是否存在信息泄漏（逐项检查训练集统计量）
3. 是否有实现错误（用可手算的小例子验证）
4. 只有在 1-3 都排除后，才讨论方法本身
```

### 模板 C：审查自己的结论

```
请审查我下面这个结论，找出所有"超出证据"的地方：
<结论>
逐条回答：这句话有数据支撑吗？如果没有，应该怎么改写才严谨？
```

> **模板 B 是本项目最救命的一条。**
> 曾经测出「欧氏对齐增益≈0」，与文献的 +5~15% 严重不符。
> 按这个顺序排查，发现是**校准跨了 session**——方法没错，用法错了。
> 改成同 session 校准后，增益恢复到 +2.94 pp。

## 4. 已验证的效果

| 项 | 结果 |
|---|---|
| 受控测出的改进 | FBCSP +3.79 pp、欧氏对齐 +2.94 pp |
| 被实测否掉的改进 | NBPW 换分类器（−0.02~+0.48）、EOG 回归（−0.92 逐试次）、多时间窗（−2.07 与 EA 组合） |
| 避免的误判 | 2 次（跨 session 校准、对照基线域不匹配） |
| 端到端 | 73.98% → **80.32%（kappa +0.480 → +0.606）** |

**特别有价值的一点**：三个优化项里，**有两个的预期方向是错的**——
模型预判 EOG 回归 +1~3 pp，实测 −0.92；预判多窗 +1~3 pp，实测与 EA 组合后 −2.07。
**只有实测才能纠正预期。**

---

## 5. 失效条件

| 条件 | 说明 |
|---|---|
| 改进项强耦合、无法分离 | 2×2 不够，需要更多因子设计或改用效应量估计 |
| 样本量太小 | 单次划分的差异可能只是噪声，需要多次重复取均值±标准差 |
| 跨数据集比较 | 只能比趋势；绝对值受数据集难度影响，不可直接相减 |
| 测试集参与超参选择 | 结果必然乐观，所有数字都不可信 |

---

## 6. 来源

- **失败**：把"跨 session 校准"当成"同 session"用，EA 增益测出≈0，差点写进结论"该方法无效"
- **失败**：对照组用了已对齐的训练数据配未对齐的测试数据，基线被压到 72.6%，归因全错
- **失败**：两套实现（MATLAB / Python）直接比绝对值，把实现 bug 当成了算法差异
- **观察**：把 2×2 消融做出来后，"换分类器没用"这个反直觉结论才站得住
