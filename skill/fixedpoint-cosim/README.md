# 定点化与逐级对拍

> 类型：**校验脚本 + 踩坑清单**
> 验证状态：✅ 定点 vs 浮点损失 **+0.04 pp**；RTL 与整数参考 **744 包零错误、两级逐位一致**

---

## 1. 适用场景

- 浮点算法要定点到 FPGA / DSP / MCU
- 已经定点完，但不知道位宽够不够、误差从哪来
- 上板结果和仿真对不上

**不适用**：纯浮点实现（DSP 有 FPU 且性能够）；或算法对量化天然不敏感。

---

## 2. 使用方法

### 步骤 1　先做位宽余量检查（上板前）

```bash
python check_qmargin.py --demo        # 看演示，理解什么情况会翻车
python check_qmargin.py params.json   # 检查你自己的参数
```

**退出码 1 表示有参数会饱和。** 这是最便宜的一道关——综合前几秒钟就能查完。

### 步骤 2　确认三个"想当然"的维度

| 量 | 常见错误 | 正确做法 |
|---|---|---|
| 分量数 | 按 `2m` 算 | **`min(2m, N)`**，受通道数限制 |
| 特征总维 | 等于通道数 | `子带数 × 分量数` |
| 实际使用维 | 等于特征总维 | 特征选择后的数量（可能又少一截） |

三者互不相等。**全部做成可配的宏/寄存器**，不要硬编码。

### 步骤 3　利用算法不变性，免费换取位宽

**如果某个参数在下游只以"比值"或"归一化"形式出现，那么整体缩放它不改变任何输出。**
此时先把参数归一化到接近满量程再量化，可以把整数位压到最小。

本项目实例：

```
特征定义  f_i = log( var(z_i) / Σ_j var(z_j) )
缩放 W → αW  ⇒  z → αz  ⇒  var → α²var  ⇒  比值不变  ⇒  f 完全不变
```

效果：折叠类变换把权重动态范围推到 3.81，直接量化需要 18 bit；
**归一化到 max=0.875 后 16 bit 就够**，特征误差 2.5e-4（规格要求 <1e-3）。

### 步骤 4　逐级对拍（不是只看最终结果）

冻结下面四样东西，逐级比较：

```
冻结输入 + 冻结参数 + 冻结复位状态 + 唯一评分窗口
```

**必须在每一级 dump，不能只看最终准确率。**
本项目的对拍点：原始样本 → 滤波输出 → 投影 → 方差 → 特征 → 决策值。

> 只比最终结果的话，"准确率差不多"会掩盖中间某一级的偏差。

## 3. 踩坑清单

| # | 坑 | 触发条件 | 排查步骤 |
|---|---|---|---|
| 1 | **Q 格式余量不足** | 系数接近满量程（如 `b1 ≈ −1.99` 在 Q2.14/16bit 下只剩 0.3%） | 跑 `check_qmargin.py`；余量 <20% 就升位宽 |
| 2 | **宽位饱和比较拖垮时序** | 写 `(y > 上限) ? 上限 : y`，`y` 有 64 位 | 改成对高位做归约判断（`y[MSB-1:DW-1] != 0` 即溢出） |
| 3 | **查表索引边界回绕** | 索引是 8 位、表长 255 | 索引加 1 前先扩位；或表长取 2 的幂 |
| 4 | **折叠后喂错数据层** | 把参数折进下游后，仍然喂"已处理过"的数据 | 写等效性断言：`fold(x) 与 safe(x) 的输出必须逐位一致` |
| 5 | **定点 log 只是直接调 `log2`** | 只在浮点仿真里验证，没模拟 LUT | 单独验证 log 这一级：512 点表 + 线性插值的误差要单独量 |
| 6 | **复位状态未对齐** | 浮点模型从零状态，RTL 从随机初值 | 对拍前显式复位两边 |

### 坑 2 的补充（很有价值）

同一个手法在本项目四处都用上了（去直流 / 滤波 / 投影 / SVM）：

```verilog
// ✗ 差：全宽减法器比较，64 位要 16 级 CARRY4
assign y_sat = (y_ext > LIMIT) ? LIMIT : y_ext;

// ✓ 好：只看高位是否非零，几级就够
wire ovf = |y_ext[DW_EXT-1 : DW_OUT-1];
assign y_sat = ovf ? {y_ext[DW_EXT-1], {DW_OUT-1{1'b0}}} : y_ext[DW_OUT-1:0];
```

**改这一处，WNS 从 −1.6 ns 提到 −0.4 ns。**

## 4. 已验证的效果

| 项 | 结果 |
|---|---|
| 定点 vs 浮点准确率 | **+0.04 pp**（80.36% vs 80.32%），9 被试平均 |
| RTL vs 整数参考 | **744 包零错误，两级逐位一致**（原始样本、滤波输出） |
| 位宽方案 | IIR Q3.14/18bit、权重 Q1.14/16bit（归一化后）、特征 Q4.11、偏置 Q8.23 |

---

## 5. 失效条件

| 条件 | 说明 |
|---|---|
| 参数被下游**非线性**使用 | 缩放不变性不成立，不能靠归一化省位宽 |
| 算法含累加/积分 | 缩放会改变累加结果，需要额外定标推导 |
| 对拍时窗口/取整方式不一致 | 任何一处不一致，逐位比较必然失败，先统一口径再查 |
| 换了器件 DSP 位宽 | 25×18 的装法要重新核对 |

---

## 6. 来源

- **失败**：`einsum` 下标写错导致投影用了 pattern 矩阵而非 filter 矩阵，**静默偏差数周**
- **失败**：CSP 权重按 Q2.14/16bit 定标，折叠后量级升到 3.81 **直接溢出**，8 通道下 5~10 个权重饱和
- **失败**：全宽饱和比较让 WNS 卡在 −1.6 ns，改成高位归约后立刻改善
- **失败**：对数查表索引到 255 时回绕，只有新参数下的边界样本才触发，固定测试向量没抓到
- **观察**：逐级对拍抓到过一次"最终准确率看着正常、中间 `Sz` 差 161"的问题
