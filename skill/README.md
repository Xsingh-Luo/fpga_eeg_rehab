# 可复用技能包（Skill packages）

本目录把项目过程中**沉淀下来的经验显式化**，供其他队伍直接搬到自己的题目上。
每一项独立成包，内含 `README.md` 说明**适用范围、使用方法、失效条件**。

## 怎么用

1. 先看下面的索引表，找到与你当前卡点最接近的包；
2. 读该包 `README.md` 的「适用场景」和「失效条件」——**先确认适用，再抄方法**；
3. 脚本类可直接运行（仅依赖 Python 标准库 / bash，无需安装任何东西）。

> **重要**：所有包都写明了「已验证」与「未验证」的边界。
> 我们的失败大多来自"把未验证的推断当成已验证的结论"，所以这个边界必须保留。

## 早期沉淀的三条经验（保留原文）

### Serial acquisition configuration audit
适用：ADS1299/Cyton 读数为零、短接输入或饱和时。先保存寄存器原值，再核对电源位、输入 MUX、增益和参考，发送最少必要配置并读回。保留前后差异。已观察本项目 E1 关断/短接和 69 短接输入，Normal 配置读回 68 后可采到非零信号。非零不是有效 EEG 或准确率证据。失效条件：不同固件/通道设置，不能盲用本项目命令；必须按对应手册解码。

### Integer and RTL comparison
适用：定点滤波、特征与分类流水线。冻结原始输入、参数、复位状态和唯一评分窗口，同时记录编码决策字和分类位，逐输出与整数参考比较。区分实现一致性、标签命中率和新受试者泛化。本项目四类输入均有 RTL 对拍结果。表尾索引加 1 须扩位，避免 255 回绕 0。失效条件：参数缩放、全局归一化、取窗或复位不一致时不可直接比较。

### Deployment and safe shutdown
适用：Linux 控制 FPGA 并记录数据的独立设备。记录板卡/器件、时钟、引脚和寄存器身份；部署前校验哈希、测试 ABI、备份现有文件，拒绝覆盖未知版本。关机经 init 正常流程，检查持久存储不可写后才提示断电。失效条件：换板、设备树或关机服务顺序变化时须重新核对；不能凭固定等待秒数声称安全。

## 这些经验的共同来历

| 技能包 | 从哪次失败/观察中总结 |
|---|---|
| 软硬件划分 | 曾被问「为什么接 PL 不接 PS」，才发现原论证（PS 会丢字节）**漏算了 Linux tty 缓冲 355 ms**，论据不成立 |
| 定点化对拍 | 曾因 `einsum` 下标写错，**静默偏差数周**；方阵让转置错误完全不报错 |
| 静默错误猎杀 | 6 个错误里有 3 个"跑起来完全正常、数字看着也合理" |
| 归因纪律 | 曾把跨 session 校准当成同 session 用，**EA 增益测出来≈0**，差点误判方法无效 |
| PYNQ 迁移 | 为了"换板只改 3 处"，前期就把板级差异全部隔离到 XDC / 基地址 / 编译目标 |

**这些包不是"最佳实践汇编"，是踩过的坑的复盘。** 每条都能指到一次具体的失败。
