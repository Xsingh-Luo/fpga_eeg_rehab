## 1. ⚠️ 本轮发现的三个坑（都会让结果静默偏差）

### 坑 1：CSP 投影方向写反

```python
# 错误：算的是 W·x，用的是 pattern 矩阵
Z = np.einsum("cd,ndt->nct", W, X)
# 正确：z = Wᵀx，W 的**列**是空间滤波器
Z = np.einsum("cj,nct->njt", W, X)
```

**为什么没暴露**：2b 只有 3 通道，`W` 是 3×3 方阵，einsum 不报错，结果也"看着合理"。直到测 `m=1` 时矩阵变成 3×2 非方阵才崩溃。

> **教训**：矩阵方向约定必须有数值自检，**方阵会让转置错误静默通过**。

### 坑 2：群延迟漏了 2π

`rad/Hz` 换算成秒要除以 $2\pi$。`design_check.py` 与 `export_fbcsp_filters.py` 都漏了。

**用 FIR 的解析值交叉验证抓到的**：128 抽头的群延迟必然是 $(128-1)/2/250 = 254$ ms，而代码算出 1596 ms $= 254\times2\pi$。又用**脉冲响应能量重心**独立复核（频域 55.6 ms vs 时域 56.6 ms）。

| 滤波器 | 原来（错） | **正确** |
|---|---|---|
| 单带 Cheby2 10 阶 [8,30] | 272 ms | **43 ms** |
| FIR 汉明 128 抽头 | 1596 ms | **254 ms** |
| 3 带 Butterworth 各带中心 | 345 ms | **55 ms** |

### 坑 3：EA 折叠后**双重对齐** ★ 最容易犯

```matlab
Weff = Mb.' * W;              % ★ 折叠
% 错误：再喂已对齐的数据 → 等于把 M 施加两次
acc = eval(csp_features(Bs_aligned, Weff), ...)
% 正确：喂**未对齐**的原始数据
acc = eval(csp_features(Bs_raw, Weff), ...)
```

因为 $W_{\text{eff}}^Tx = (M^TW)^Tx = W^TMx = W^Tx_{\text{aligned}}$。

**后果**：准确率从 80.3% 掉到 74.5%（−5.8 pp），但代码不报任何错。

### 坑 4：golden vector 的三个维度错误 ★ 同批发现

生成对拍基准时踩到三个静默错误，都会让 PL 对拍"永远对不上"却查不出原因：

| 错误 | 现象 | 原因 |
|---|---|---|
| **`cell2mat` 横向拼接** | `feat_expected` 是 (2×3) 而非 (6×1) | 3 个 `(n_comp×1)` 被**横着**拼；应该用 `vertcat(fv{:})` |
| **隐式广播** | `decision` 是 (4×4) 而非标量 | `(4×1)−(1×4)` 触发广播；应显式写成 `((f'−mu)./sd)*w + b` |
| **输入截断过短** | `input_int16` 只有 50 个采样点 | 覆盖不了 626 点的分析窗，PL 无法从输入复算 |

> **教训**：**对拍基准本身必须做维度断言**。基准错了，后面所有对拍都是白费。
> 现在 `golden_vectors.mat` 已有 Python 侧的自动校验（结构 + 维度 + 索引一致性）。

| 步骤 | 准确率 | kappa | 增量 |
|---|---|---|---|
| 单带 CSP + 线性 SVM | 75.48% | +0.510 | — |
| + FBCSP6 | 76.78% | +0.536 | +1.30 |
| **+ 欧氏对齐 EA** | 79.49% | +0.590 | **+2.71** |
| + 改用 3 带 / m=1 / k=4 | 79.97% | +0.599 | +0.48 |

### 2.2 MATLAB 侧 · 真实部署口径（**权威**）

**★ 关键：EA 的校准必须与正式任务在同一个 session 内**

| 校准口径 | 结果 |
|---|---|
| **session 内校准**（真实场景：到位 → 校准 20 试次 → 做任务） | **EA +2.94 pp** ✅ |
| 跨 session 校准（把 04E+05E 拼起来取前 N 个） | EA ≈ 0 甚至为负 ❌ |

后者是实验设计错误——EA 的设计前提正是"用**目标域自己**的数据估白化矩阵"。

**session 内校准的完整结果（因果滤波）**

| 校准试次 N | 有 EA | 无 EA | EA 增益 | kappa(EA) |
|---|---|---|---|---|
| 10 | 80.07% | 77.88% | +2.19 | 0.601 |
| **20** | **80.32%** | 77.38% | **+2.94** | **0.606** |
| 40 | 79.85% | 77.60% | +2.25 | 0.597 |
| 80 | 78.82% | 77.66% | +1.16 | 0.576 |

**N=20 最优**：既充分又稳定。N=10 可用但不稳，N=80 反而退化（session 内漂移）。

### 2.3 子带数

| 子带配置 | 准确率（含 EA） |
|---|---|
| **3 带**（8-16 / 16-24 / 24-32） | **79.40%** |
| 4 带 | 79.77% |
| 6 带 | 79.03% |
| 9 带 | 78.47% |

**3 带最优且最省。** 窄带（4 Hz）群延迟长、噪声多，宽带（8 Hz）反而更好。

## 4. 最终配置

```
① 预处理      去 DC（一阶高通 0.5 Hz）
② 滤波器组    3 个子带：8–16 / 16–24 / 24–32 Hz，4 阶巴特沃斯（2 个二阶段/带）
③ 欧氏对齐    ★ 逐带、**session 内**用 20 个校准试次算 R̄_b → M_b = R̄_b^(-1/2)
              折叠：W_eff = M_bᵀ · W̃_b   （PL 零改动）
④ CSP         每带 m=1 → n_comp = min(2m, N) = 2
⑤ 特征        归一化对数方差，3 带 × 2 = 6 维
⑥ 特征选择    MIBIF 选 4 维（PC 离线，导出索引表）
⑦ 分类器      线性 SVM（折叠后 4 个权重 + 1 个偏置）
```

### 4.2 ★ 定点格式的重要变更：CSP 权重必须升到 Q3.14 / 18 bit

**EA 折叠放大了 CSP 权重的动态范围**：$W_{\text{eff}} = M^TW$ 里的 $M=\bar R^{-1/2}$
在 $\bar R$ 有小特征值时会放大权重。

| | 未折叠 $W$ | **折叠后 $W_{\text{eff}}$** |
|---|---|---|
| 实测最大绝对值 | < 2.0 | **3.81**（B03） |
| Q2.14 / 16 bit（±2.0） | 刚好 | **溢出** ❌ |
| **Q3.14 / 18 bit（±4.0）** | 有余量 | **余量 63~75%** ✅ |

**结论：CSP 权重的格式从 Q2.14/16bit 改为 Q3.14/18bit**（与 IIR 系数同格式）。
已实测溢出检查全过：

```
[ OK ] IIR 系数  带1/2/3 Q3.14    最大 32768 / 上限 131071  (余量 75%)
[ OK ] CSP 权重  带1 Q3.14        最大 48952 / 上限 131071  (余量 63%)
[ OK ] CSP 权重  带2 Q3.14        最大 36735 / 上限 131071  (余量 72%)
[ OK ] CSP 权重  带3 Q3.14        最大 35531 / 上限 131071  (余量 73%)
[ OK ] SVM 权重 Q4.11             最大  6254 / 上限  32767  (余量 81%)
[ OK ] SVM 偏置 Q8.23             最大 8647949                (余量 100%)
[ OK ] 去DC 系数 Q1.15            最大 32361 / 上限  32767  (余量 1%)
```

> ⚠️ 去 DC 系数 Q1.15 余量只有 1%——因为 $a=0.9876$ 本就贴近满量程。
> **这是设计使然不是问题，但改截止频率时要重新检查。**

### 4.3 PL 资源

| 模块 | 原单带方案 | **最终配置** |
|---|---|---|
| 滤波器 | Cheby2 5 节 × 8 通道 = 40 biquad | **Butterworth 2 节 × 3 带 × 8 通道 = 48 biquad** |
| 滤波 MAC/采样点 | 200 | **240** |
| CSP 投影 | 8 通道 × 4 分量 = 32 MAC | **3 带 × 8 × 2 = 48 MAC** |
| 滑动窗分量 | 4 | **6** |
| 特征维 → SVM | 4 | **4** |
| **DSP** | ~12 | **~18–25** |
| **BRAM** | ~7 | **~9–13** |
| **利用率** | ~10% | **~13–16%** |

> **精度最优的配置恰好也是最省的**——不是巧合：3 个宽带子带（8 Hz 宽）比 6–9 个窄带（4 Hz 宽）
> 噪声更少，且窄带滤波器的长群延迟会引入子带间失配。
>
> **想提高资源利用率，正确方向是增加通道数（8 通道 vs 3 通道），不是增加子带数。**

## 6. 还有没有更优方案？—— 没有了

| 方向 | 不做的理由 |
|---|---|
| **黎曼切空间** | EA 本质是它的零阶近似，**实测已拿到最大单项增益**；且它在 trial 粒度工作，与"每 4 ms 一个决策"冲突。**只做离线对比实验** |
| **深度网络** | 9 被试 × 3 通道 × 400 试次，**数据量不足以支撑 DL**；文献高数字多含协议问题；开发成本 3–5 倍且验证困难 |
| **CSSP/CSSD** | EA 已吃掉主要收益，增量不明确而硬件代价明确 |
| **被试特异频带** | 实测 3 带已经很好；若有余力可做，须用嵌套 CV |
| **跨被试迁移** | MI 模式高度个体化，简单池化通常有害 |

**判断依据**：当前 κ 0.606 **已超过 2008 官方冠军**（0.600）。
数据集现实天花板在 κ 0.65 左右（3 通道、9 被试的固有限制）。
**再投入的边际收益很小，而每次试验都有引入新 bug 的风险——本轮三个坑就是例子。**

**建议把精力转向**：PL 实现（见 05 号文档 H 里程碑）、演示工程打磨。
