## 0. 已冻结的设计参数

> **v2.0 配置变更**：算法已从「单带 CSP」升级为「**3 子带 FBCSP + 欧氏对齐**」。
> 实测从 75.5% 提升到 **78.72%（因果）/ 79.56%（零相位）**，接近 2008 官方冠军的 80%。
> 完整数值与消融依据见 **[07 验证结果与最终配置](07_verification_and_config.md)**。

这些参数不是拍的，是拿 BCI IV 2b 真实数据扫出来的（见 `python/sweep_2b.py`、`python/design_check.py`、`python/optimize_2b*.py`）。

| 参数 | 取值 | 依据 |
|---|---|---|
| 采样率 `fs` | 250 Hz | 数据集规格；OpenBCI Cyton 同为 250 Hz |
| 通道数 `N` | 3（2b：C3/Cz/C4）｜8（自采） | 2b 就是 3 通道，与 Cyton 蒙太奇对齐 |
| 分析窗 | **[3.5, 6.0] s**（相对试次起点 768）＝ **626 点** | sweep 实测：该窗 kappa 0.577，优于 [3.0,5.0] 的 0.502 |
| **子带** | **3 个：8–16 / 16–24 / 24–32 Hz** | 实测 3 带 > 4 带 > 6 带 > 9 带；宽带噪声更少、群延迟更短 |
| **滤波器** | **每个子带 4 阶巴特沃斯（2 个二阶段）** | 相邻子带故意重叠，不需要陡峭截止 |
| **欧氏对齐** | **逐带白化，20 个校准试次，算术均值** | 最大单项增益；白化可折叠进 CSP，PL 零改动 |
| CSP 对数 `m` | **1**（`n_comp = min(2m, N)`） | 2b 下得 **2** 个分量/带 → 3 带共 **6** 维特征 |
| 特征选择 | **MIBIF 选 4 维** | PC 离线，导出索引表 |
| SVM 核 | **线性** | 线性核可折叠成单层点积，硬件代价几乎为零 |
| 评估协议 | `cross`（01T+02T+03T→04E+05E） | 官方划分，主报此协议 |
| 决策更新率 | 250 Hz（每 4 ms） | 滑动窗运行和机制，见 §4.5 |
| **因果/零相位** | **FPGA 用因果**（性能低约 0.9 pp） | 零相位需整段缓冲，只能离线用 |

> ⚠️ **`n_comp = min(2m, N)`，不是 `2m`**。3 通道下 `m=1` 得 2 个分量、`m=2` 得 3 个，MNE 会静默截断。
> **特征维必须做成可配置**，别在 RTL 里硬编码。
>
> ⚠️ **EA 折叠后 CSP 矩阵会变**：`W_eff = Mᵀ·W̃`。换被试/换 session 都要重新下发，**PL 无需改动**。

## 1. 算法链总览与级间契约

```
┌─ 训练期（PC / MATLAB，浮点）────────────────────────────────────────┐
│  GDF 原始 ─► 去DC ─► 3 子带带通 ─► 分段[3.5,6] ─► 剔伪迹 ─► 去均值   │
│      每带独立：                                                      │
│        协方差 R_c ─► LW 正则化 ─► Cc=C1+C2 ─► 白化 P ─► eig(P·C1·Pᵀ)│
│        ─► W̃ (N×n_comp) ─► 投影 z ─► 对数方差归一化 f               │
│      3 带拼接 ─► MIBIF 选 4 维 ─► SVM 训练                          │
│      ─► 【参数】(W̃, w, b) + 【golden vector】                        │
│                                                                      │
│  部署前：欧氏对齐折叠  W_eff = Mᵀ·W̃   （每带独立）                  │
└──────────────────────────────────────────────────────────────────────┘
                                  │  AXI-Lite 下发 W_eff, w, b
┌─ 推理期（PL / 定点，全流水）──────────▼─────────────────────────────┐
│  x[n] ─► 去DC ─► 3 带并行 IIR ─┬─► z_b = W_eff,bᵀ x_b  (b=0,1,2)    │
│                                 └─► 滑动窗 Σz,Σz² ─► 归一化 ─► log2 │
│      ─► 取 MIBIF 选中的 4 维 ─► w·f+b ─► 标签 + 决策值 (每 4 ms)    │
│                                                                      │
│  ★ EA 已折进 W_eff，推理链路完全不感知 EA 的存在                     │
└──────────────────────────────────────────────────────────────────────┘
```

**级间契约（每级的输入/输出形状与量纲）**

| 级 | 输入 | 输出 | 训练端 | PL 端 |
|---|---|---|---|---|
| L1 去DC | `(N, T_raw)` int24 计数 | 同形状，均值≈0 | 减滑动均值 | 一阶高通 IIR |
| L2 带通 | L1 输出 | `(N, T)` × **3 带** | `scipy.signal.sosfilt` | **3 带 × 2 节** biquad 转置型 |
| L3 分段 | L2 连续流 | `(n_trials, N, 626)` | `mne.Epochs` | 由试次起点触发取窗 |
| L4 去均值 | L3 | 同形状，每 trial 每通道零均值 | `X - X.mean(axis=2)` | 由 L1 的高通保证 |
| **L4.5 EA** | `(n_trials, N, 626)` × 3 带 | 同形状 | `euclid_align`（20 试次校准） | **折叠进 L6，无独立模块** |
| L5 协方差 | `(n_trials, N, 626)` | `(N, N)` × 2 类 × 3 带 | 见 §2.4 | **不做**（训练期专属） |
| L6 CSP 投影 | L4.5 + `W_eff` | `(n_trials, n_comp, 626)` × 3 带 | `np.einsum('cj,nct->njt', W, X)` | `z = Wᵀx` |
| L7 特征 | L6 | `(n_trials, 6)` | 归一化对数方差 | 滑动窗运行和 + log |
| L8 判别 | L7 的 4 个选中维 + `(w, b)` | 决策值 → 标签 | `sklearn` / MATLAB | 点积 + 比较 |

> ⚠️ **L6 的 einsum 极易写错**：`W` 的形状是 `(N, n_comp)`，其**列**才是空间滤波器，
> 所以必须是 `'cj,nct->njt'`（即 $W^Tx$）。
> 写成 `'cd,ndt->nct'` 会算成 $Wx$——用的是 pattern 矩阵而非 filter 矩阵。
> **3 通道时 `W` 是 3×3 方阵，这个错误不会报错，结果也"看着合理"。**
> `design_check.py` 里用 MNE 的 `filters_`（形状 `(n_comp, N)`，行是滤波器）时才是 `'cd,ndt->nct'`。

### 2.2 预处理：去 DC + 带通

**去 DC 为什么必须做**：ADS1299 有数百 mV 级直流偏移，而 EEG 只有 ±100 µV，动态范围比 ~2000:1。不去 DC 就得白白多留 11 bit 位宽。

**滤波器选型（`design_check.py` 实测 @ 250 Hz）**

单带方案（早期，已被 3 带 FBCSP 取代，保留作为对照）考核点：8–30 Hz 通带，5/45 Hz 抑制 ≥40 dB。

| 方案 | 规模 | 带内起伏 | 5Hz 抑制 | 群延迟@12Hz | 最大群延迟 |
|---|---|---|---|---|---|
| Butterworth 8 阶 | 4 节 | 1.29 dB | −23.0 dB | 53 ms | 125 ms |
| 椭圆 8 阶 rp0.5/rs40 | 4 节 | 0.50 dB | −41.8 dB | 55 ms | 282 ms |
| **Cheby2 10 阶 rs40** | **5 节** | **0.11 dB** | **−42.3 dB** | **43 ms** | **142 ms** |
| Cheby2 14 阶 rs60 | 7 节 | 0.06 dB | −69.1 dB | 64 ms | 231 ms |
| FIR 汉明 128 抽头 | 128 tap | 0.71 dB | −42.4 dB | **254 ms** | 254 ms |
| FIR 汉明 200 抽头 | 200 tap | 0.06 dB | −56.4 dB | **398 ms** | 398 ms |

**★ 最终方案：3 个子带，每个 4 阶巴特沃斯（2 个二阶段）**

| 子带 | 节数 | 带内起伏 | 邻带抑制 | 带中心群延迟 |
|---|---|---|---|---|
| 8–16 Hz | 2 | 3.00 dB | −11.6 dB | 54.5 ms |
| 16–24 Hz | 2 | 3.00 dB | −9.4 dB | 55.6 ms |
| 24–32 Hz | 2 | 3.01 dB | −8.8 dB | 55.9 ms |

**为什么低阶就够**：FBCSP 相邻子带**故意重叠**，不需要陡峭截止。
追求陡峭截止会让每带要 5–8 节，9 带就是 72 个 biquad——而 3 带 × 2 节只要 **6 个 biquad/通道**。

**为什么选 3 带而不是 6/9 带**（实测）：3 带 79.40% > 4 带 79.77% > 6 带 79.03% > 9 带 78.47%（含 EA）。
窄带（4 Hz）滤波器群延迟长达 111 ms 且噪声更多，宽带（8 Hz）反而更好且更省。

> **群延迟的正确算法**：`rad/Hz` 换算成秒要**除以 2π**。本轮用一个 FIR 的解析值交叉验证过：
> 128 抽头的群延迟必然是 $(128-1)/2/250 = 254$ ms。还额外用脉冲响应能量重心独立复核（频域 55.6 ms vs 时域 56.6 ms）。

**子带滤波器设计参数**

```python
# 3 个子带，每个用 2 阶原型 → 带通后 4 阶 = 2 个二阶段

    sos = signal.butter(2, [lo, hi], btype="band", fs=250, output="sos")   # (2, 6)
```

**SOS 系数（Q2.14 定点，已核对不溢出）**

```c
// 转置直接 II 型：y[n] = b0·x[n] + b1·x[n-1] + b2·x[n-2] - a1·y[n-1] - a2·y[n-2]
// scipy sos 行格式 [b0,b1,b2,1,a1,a2]，此处 a0 已省略
static const int32_t CHEB2_SOS_Q14[5][5] = {   // {b0, b1, b2, a1, a2}
    {    348,     3,    348, -16006,  6810 },   // 节1  通带峰值增益 0.099
    {  16384,     0, -16384, -21165,  6541 },   // 节2  增益 3.33
    {  16384,-13020,  16384, -19662, 12801 },   // 节3  增益 3.70
    {  16384,-32665,  16384, -29130, 13257 },   // 节4  增益 1.13
    {  16384,-32526,  16384, -31303, 15436 },   // 节5  增益 1.84
};
```

> ⚠️ **两个实现要点**：
> 1. **系数位宽建议提到 18 位 Q3.14**。节4/节5 的 `b1 ≈ −1.99`，在 Q2.14（16 bit）下只剩 0.3% 余量，工程上太险。
> 2. **各节通带峰值增益差 37 倍**（0.099 ~ 3.70），第 1 节会把信号压低 ~3.3 bit。定点实现时**状态位宽要按最坏节点留余量**（Q4.19 的 24 bit 状态足够），或做逐节增益重分配。

**定点仿真验证（真实数据 B0101T / C3 / 24 s）**

| 系数格式 | 状态 | 累加器 | 输出 SNR |
|---|---|---|---|
| Q2.12 | Q4.19 | 48 bit | 44.4 dB |
| **Q2.14** | Q4.19 | 48 bit | **59.8 dB** |
| Q2.16 | Q4.19 | 48 bit | 60.2 dB |

→ **Q2.14 已足够，再往上加位数没有收益**（受限的不是系数量化）。建议直接用 18 位 Q3.14，SNR 还有余量。

### 2.4 CSP 训练（只在 PC 上做）

**逐步公式**（对应你 `CSP/csp0.m` 里的逻辑，这里补上部署相关的细节）：

```
① 每 trial 去均值：  X ← X − mean(X, axis=time)
② 单 trial 协方差：  R_c = X·Xᵀ / trace(X·Xᵀ)          ← 迹归一化，消除 trial 间幅度差
③ 类平均：           C1 = mean(R_c | c=1)， C2 同理
④ 正则化：           C ← (1−α)·C + α·(trace(C)/N)·I     ← α=0.05
                     ★ 实现上直接用 Ledoit-Wolf 收缩（MNE 的 reg='ledoit_wolf'），
                       比固定 α 更稳，小样本下差别明显
⑤ 复合：             Cc = C1 + C2
⑥ 白化：             [U,D] = eig(Cc);  P = U·D^(−1/2)·Uᵀ
⑦ 白化后类协方差：   S1 = P·C1·Pᵀ
⑧ 特征分解：         [V,L] = eig(S1)，按特征值降序排
⑨ **空间滤波器：     W = Pᵀ·V**                        ← 这就是要下发给 PL 的矩阵
⑩ 取分量：           保留首 m 列与末 m 列（首=类1方差大，末=类2方差大）
                     ★ 实际受通道数限制：n_comp = min(2m, N)
```

**实现**：`mne.decoding.CSP(n_components=2*m, reg='ledoit_wolf', log=False, norm_trace=False)`，取 `csp.filters_`（形状 `(n_comp, N)`），转置成 `W (N, n_comp)` 下发。

> `log=False` 是刻意的 —— 特征要自己做，理由见 §2.5。

### 2.5 ★ 特征提取：必须自己实现归一化版本

**MNE 的 `CSP(log=True)` 算的是 `log(var)`，不含归一化**，这是一个必须知道的坑。

| 定义 | 公式 | Σf 是否恒定 | 对全局缩放 |
|---|---|---|---|
| MNE `log=True` | `fᵢ = log(var(zᵢ))` | ❌ 随 trial 波动（−2.285 ± 0.879） | ❌ 缩放 a 倍 → 整体平移 2·ln a |
| **经典 CSP 定义** | `fᵢ = log(var(zᵢ) / Σⱼ var(zⱼ))` | ✅ 恒为常数（−3.369 ± 8.4e−2） | ✅ **完全不变** |

**实测（B01 训练集 400 试次，固定 W 不变、把输入放大 100 倍模拟增益标定差 40 dB）**：

```
MNE log(var)         特征变化量 Δmax = 9.210   ← 正好等于 2·ln100，完全跑偏
归一化 log(var/Σvar)  特征变化量 Δmax = 4.4e−16 ← 恒定不变
```

**两种定义的精度基本无差**（5 折：73.00% vs 72.50%），但归一化版本带来三个部署上的实质好处：

1. **PL 端不需要精确增益标定**，ADC 计数域直接算，省掉 ×0.02235 的 μV 换算；
2. **对通道间增益差异免疫**（ADS1299 各通道增益误差被归一化吸收）；
3. **换电极/换被试时的阻抗差异不会平移特征**。

**实现（显式写出来，不依赖 MNE 内部约定）**：

```python
def extract_features(X, W):
    """X: (n_trials, N, T) 已去均值；W: (N, n_comp)"""
    Z = np.einsum("cd,ndt->nct", W, X)      # 投影 z = Wᵀx
    var = Z.var(axis=2)                      # (n_trials, n_comp)
    return np.log(var / var.sum(axis=1, keepdims=True))
```

> ⚠️ **归一化会改变特征尺度**，所以 SVM 的 `C` / `γ` 必须在**同一套特征**上重训，不能把浮点旧参数直接搬过来。这也意味着 §7 的参数导出流程必须"先定特征定义，再训 SVM"。

### 2.6 SVM 训练与 ★ 线性核折叠

**主线：线性核**。原因是它可以在硬件上折叠：

```
决策函数：  d(f) = Σᵢ αᵢ·yᵢ·K(f, svᵢ) + b
线性核：    K(f, svᵢ) = f·svᵢ
⇒ 折叠：    d(f) = (Σᵢ αᵢ·yᵢ·svᵢ)·f + b  =  w·f + b
            其中 w = dual_coef_ @ support_vectors_   （sklearn 里就是一行矩阵乘）
```

**等价性实测**（400 样本 / 3 维特征 / 144 个支持向量）：

```
折叠前后决策值最大差 = 1.812e−13      （浮点舍入量级）
预测标签完全一致     = True
```

**含义（很重要）**：
- 实测基线里 B01 有 **261 个支持向量**，看着很多 —— 但线性核折叠后 PL 只需要存 **3 个权重 + 1 个偏置 = 4 个数**；
- 硬件就是一个 3 乘加 + 比较器，**比存 261 个 SV 省两个数量级的 BRAM**；
- 所以**先做线性核，RBF 作为进阶对照**（RBF 不能折叠，必须存全部 SV 并实现 `exp`）。

**RBF 核（对照）**：`d(f) = Σₖ αₖ·exp(−γ‖f − svₖ‖²) + b`，K=261 时硬件代价：
- 距离展开优化：`‖f−sv‖² = Σf² − 2Σf·sv + Σsv²`，其中 `Σf²` 是公共项、`Σsv²` 可离线预算 → 每维省一次乘法；
- `exp` 用分段线性 LUT（见 §4.7）。


**★ 导出流程必须包含 EA 折叠这一步**：

```matlab
% 每个子带独立：先用 20 个校准试次估白化矩阵 M_b，再折叠进 CSP
[Mb, ~] = euclid_align(Xcal_band, 20);      % 校准数据该带的试次
W_eff   = Mb.' * W_trained;                  % ← 折叠！PL 侧只看到这一个矩阵
```

**导出时必须同时生成 golden vector**（同一批输入 + 每一级的期望输出），这是 §5 逐级对拍的依据。
golden vector 要覆盖 **EA 折叠后**的中间结果，否则 PL 对拍时无法定位是 EA 还是 CSP 出错。

### 2.8 欧氏对齐（EA）

**位置**：在每个子带带通**之后**、CSP 投影**之前**，逐带独立做。

```
X_band (n_trials, N, T)
   │
   ├─ 校准段（前 20 个试次）→ R̄_b = mean_i( XᵢXᵢᵀ / tr(XᵢXᵢᵀ) )
   │                        → M_b = R̄_b^(-1/2)      （特征分解，只在 PC/PS 做）
   │
   └─ 全部试次 → X̃ = M_b · X

然后：W_eff,b = M_bᵀ · W̃_b      ← ★ 折叠，PL 只加载 W_eff
```

**三个实现要点**

| 要点 | 说明 |
|---|---|
| **算术均值就够** | 实测算术均值与黎曼均值**结果完全相同**，不需要迭代算法 |
| **校准量 20 个试次** | 5 个不够（负增益）；10 个不稳定；20 个约 1 分钟任务 |
| **训练域用全部数据，测试域只用校准量** | 训练数据来自既往 session，可以全用；测试域必须只用校准段 |

**为什么必须做**：不同 session 的协方差矩阵整体缩放与旋转不同，导致 CSP 滤波器失配。
白化把所有域拉到同一参考系，实测是本项目**最大的单项增益**。

**对 PL 零成本**——白化折进 CSP 矩阵后，推理链路完全不感知 EA 的存在。

参考实现：`matlab/euclid_align.m`。

### 3.3 各算子的定点实现

| 算子 | 实现方式 | 实测/说明 |
|---|---|---|
| **一阶高通去DC** | `y[n] = a·(y[n−1] + x[n] − x[n−1])`，a=0.9876@Q1.15 | 截止 0.5 Hz |
| **biquad** | **转置直接 II 型**：`y = (b0·x + s1)>>14`；`s1 = b1·x − a1·y + s2`；`s2 = b2·x − a2·y`。状态与累加器 48 bit 饱和 | 转置型反馈路径只有 1 次乘加，时序好收敛；直接 I 型反馈链更长 |
| **滑动窗方差** | 维护 `Sz`、`Sz2` 运行和，**每拍加新减旧**；`var = (Sz2 − Sz²/T)/T` | ★ 全整数加减 → 数学上零漂移。仍保留"每 2 s 从零重算"的兜底开关（可配） |
| **倒数 1/S** | Newton-Raphson：`y ← y·(2 − S·y)`，初值查表，**2 次迭代** | 避免除法器；32 bit |
| **log2** | 前导零计数得整数部分 + 尾数 512 点表 + 线性插值 | 相对误差 < 1e−4；见 §4.6 |
| **exp（仅 RBF）** | 输入域 `−γ‖·‖² ∈ [−20, 0]` 有界，128 段线性插值 LUT | 见 §4.7 |
| **饱和/舍入** | 全链统一 **round-half-up + 饱和**（不回绕） | 回绕会让误差爆炸且极难定位 |

### 3.4 误差预算与位宽扫描方法

**目标：定点 vs 浮点，特征相对误差 < 1e−3，分类准确率差 < 0.5%。**

扫描方法（P1 阶段执行）：
1. 固定其它位宽，逐个扫描：IIR 系数（12/14/16/18/20）、`x`（16/20/24）、`z`（20/24/28）、`f`（12/16/20）；
2. 每个配置跑 `baseline_2b.py --protocol cross` 全 9 被试；
3. 画"位宽 vs 准确率"曲线，取拐点向上留 2 bit；
4. **产出**：位宽-精度曲线图（这是资源清单 §4.5 空白点②的原创数据）。

**已知的误差主导项排序**（根据 §2.2 的定点仿真推断）：
`IIR 系数 (Q2.12→Q2.14 提 15 dB) > 状态位宽 > log 表深度 > CSP/SVM 位宽`。
所以**优先保证滤波器链的位宽，后级可以省**。

## 4. PL 实现规格（逐模块）

### 4.1 顶层与数据流

```
                    ┌──────────────────── eeg_csp_svm_top ────────────────────┐
AXIS in ─► frame_parser ─► prefilter ─► csp_project ─► win_var ─► lognorm ─► svm_core ─► 标签
 (24b×N)      (RTL)         (HLS)         (HLS)         (RTL)      (HLS)      (HLS)
                                ▲            ▲                                    ▲
                          AXI-Lite ──────────┴────────────────────────────────────┘
                          (下发 sos / W / w,b；回读状态与决策值)
```

**关键原则：中间结果不出 PL。** 只在最后把标签 + 决策值回 PS。实测 PL↔PS 往返约 4.3 µs，若每级都往返一次，延迟立刻翻十倍。

### 4.2 `frame_parser`（RTL，状态机）

- 输入：AXI-Stream，每拍 1 字节（或 24 bit 打包）
- 逻辑：找 `0xA0` 帧头 → 收 33 字节 → 校验帧尾 `0xCX` → 提取 8×24bit 大端有符号 → 抽样序号做丢包检测
- 输出：`(N, 24b)` 并行 + `frame_valid` + `seq_err`
- 丢包处理：**插入零填充并置 `pad_flag`**，保持时间轴对齐（不要让 PL 看到跳变的时间轴）

资源估计：< 500 LUT，1 个 BRAM 做行缓冲。

### 4.3 `prefilter`（HLS）—— 去DC + 3 子带滤波器组

**运算量核算**：每采样点 `N × (1 + 3带×2节×5) = N × 31` MAC。N=8、fs=250 → **62 kMAC/s**。
在 100 MHz 下一个 DSP 有 100 MMAC/s 能力 → **占用 0.06%**。

> **结论：整个滤波器组可以时间复用到 1–2 个 DSP。** 不需要 N 路并行乘法器。
> 做法：4 ms 采样间隔（@100 MHz 有 400,000 周期）里，用 240 个周期跑完 8 通道 × 3 带 × 2 节。

**状态规模**：`N × 3带 × 2节 × 2状态`。N=8 时是 96 个 24 位状态 → 放 LUTRAM 或 1 个 BRAM，不占 LUT。

**HLS 骨架**：

```cpp
#include "ap_fixed.h"
typedef ap_fixed<24, 10> samp_t;      // Q8.15
typedef ap_fixed<18, 4>  coef_t;      // Q3.14
typedef ap_fixed<48, 30> acc_t;

#define N_BAND 3                      // 8-16 / 16-24 / 24-32 Hz
#define N_SEC  2                      // 每带 2 个二阶段（4 阶巴特沃斯）

void prefilter(stream_t &in, stream_t &out,
               const coef_t sos[N_BAND][N_SEC][5], int n_ch) {
  static acc_t s1[8][N_BAND][N_SEC], s2[8][N_BAND][N_SEC];   // 状态放 BRAM/LUTRAM
  for (int c = 0; c < n_ch; c++) {
    samp_t x = in.read();
    #pragma HLS PIPELINE II=1
    for (int b = 0; b < N_BAND; b++) {
      samp_t y = x;                                    // 同一个 x 送进 3 个带
      for (int k = 0; k < N_SEC; k++) {
        acc_t acc = sos[b][k][0]*y + s1[c][b][k];
        samp_t yn = acc >> 14;
        s1[c][b][k] = sos[b][k][1]*y - sos[b][k][3]*yn + s2[c][b][k];
        s2[c][b][k] = sos[b][k][2]*y - sos[b][k][4]*yn;
        y = yn;
      }
      out.write(y);                                    // 每带一路输出
    }
  }
}
```

**时序注意**：biquad 的反馈路径只有 `s1 → acc → yn → s1`，中间 1 次乘加，在 100 MHz 下打 1 拍即可收敛。**不要用直接 I 型**（反馈链含两级累加，时序差）。

**★ 3 带输出要并行留给下游**：`csp_project` 需要同时看到 3 个带的样本。
若为省引脚把 3 带串行化，CSP 就得缓存——**不划算**，直接做成 3 路并行总线。

### 4.4 `csp_project`（HLS）

`z = Wᵀx`，`(n_comp×N)` 个 MAC。N=3/8、n_comp=3/4 → **最多 32 MAC/采样点**，完全串行都够。

```cpp
void csp_project(samp_t x[8], const coef_t W[8][4], samp_t z[4], int n_ch, int n_comp) {
  #pragma HLS ARRAY_PARTITION variable=W complete dim=0
  for (int j = 0; j < n_comp; j++) {
    #pragma HLS PIPELINE II=1
    acc_t acc = 0;
    for (int c = 0; c < n_ch; c++) acc += (acc_t)W[c][j] * x[c];
    z[j] = acc >> 14;                  // Q3.14 × Q8.15 → Q10.13
  }
}
```
`W` 存 BRAM，**支持运行时经 AXI-Lite 重载**（换被试不用重新综合 —— 这是答辩的加分点）。

### 4.5 ★ `win_var`（RTL）—— 滑动窗运行和，全链最关键的技巧

**朴素做法**：每出一个决策就把窗内 626 点重算一遍 → 626 × n_comp 次乘加，浪费且延迟大。

**正确做法**：维护 `Sz`、`Sz2` 两个运行和，**每个新采样点只做一次加法、一次减法**：

```
每来一个新的 z：
    Sz [j] += z[j] − z_old[j]
    Sz2[j] += z[j]² − z_old[j]²
其中 z_old 从深度 T 的环形缓冲读出。
窗口满后，任意时刻都能立刻给出：
    mean = Sz/T
    var  = Sz2/T − mean²          （等价于 (Sz2 − Sz²/T)/T）
```

**为什么这样做是对的**：
1. **运算量从 O(T) 降到 O(1)**：626 次乘加 → 1 乘 2 加减；
2. **整数加减是精确的 → 理论上零漂移**（不像浮点累加会掉精度）。仍保留"每 2 s 从零重算一次"的兜底开关，防极端情况；
3. **决策更新率可以做到 250 Hz** —— 每个采样点都能出一个标签，这是相对 PC 批处理的核心优势（见 00 号文档 §2.3）。

**资源**：环形缓冲 `z` 历史 = `n_comp × T × 24 bit`。3×626×24 = 5.6 KB → **2 个 BRAM36**。四路的话 8 KB，4 个 BRAM36。

**边界处理**：窗口未满时不输出决策（或输出 `valid=0`）；试次起点（768）应触发一次 `clear_accum` 以对齐。

### 4.6 `lognorm`（HLS）

```
① S = Σⱼ varⱼ                                  （n_comp−1 次加法）
② inv_S = 1/S     ← Newton-Raphson，初值查表，2 次迭代
③ rⱼ = varⱼ · inv_S                            （n_comp 次乘法），Σr = 1
④ l2ⱼ = log2(rⱼ)  ← 前导零计数 + 512 点尾数表 + 线性插值
⑤ fⱼ = l2ⱼ · ln2  ← ln2 = 0.6931 @ Q1.15
```

**log2 的实现细节**（这是特征级的核心算子）：
- `r ∈ (0, 1]` → `l2 ≤ 0`。先规格化：`r = m · 2^e`，`m ∈ [1,2)`，`e` 由前导零计数得到（负数用补码处理）；
- `log2(r) = e + log2(m)`，`log2(m)` 用 512 项表 + 线性插值，`m ∈ [1,2)`；
- 表存在 BRAM（512 × 16 bit = 1 KB，不到 1 个 BRAM36）；
- 精度：512 点线性插值在 `[1,2)` 上最大误差约 `1/(8·512²)` ≈ 5e−7，远超需求。

### 4.7 `svm_core`（HLS）—— 线性版与 RBF 版

**线性版（主线，极简）**——依据 §2.6 的折叠：

```cpp
void svm_linear(const feat_t f[4], const coef_t w[4], const acc_t b,
                ap_int<32> &decision, ap_uint<1> &label, int n_comp) {
  acc_t acc = b;
  for (int j = 0; j < n_comp; j++) {
    #pragma HLS UNROLL
    acc += (acc_t)w[j] * f[j];
  }
  decision = acc;
  label = (acc > 0) ? 1 : 0;
}
```
**资源：`n_comp` 个 DSP + 加法树。延迟：`n_comp` 拍（流水后每拍一个结果，< 100 ns）。**

**RBF 版（对照）**：
```
d(f) = Σₖ αₖ·exp(−γ·‖f − svₖ‖²) + b
优化：‖f−sv‖² = Σf² − 2·Σ(f·sv) + Σsv²
      · Σf²   ：每次决策算一次，全 SV 共用
      · Σsv²  ：离线预计算，存表
      · Σ(f·sv)：K × n_comp 次 MAC（K=261、n_comp=3 → 783 MAC）
exp：128 段线性插值 LUT，输入域 [−20, 0]
```
并行度 `P`（同时算 P 个 SV）：资源 ≈ `P` 组 MAC + `P` 个 exp LUT。K=261、P=8 → 33 拍完成，**仍 < 1 µs**。7020 资源充裕。

### 4.8 AXI-Lite 寄存器与参数加载

完整映射见 [01 号文档](01_fixed_point_interface.md) §4。三个实施要点：

1. **参数下发后必须回读校验**（CRC32），`params_crc_ok=0` 时拒绝使用新参数并置错误位。静默使用半截参数会导致"精度莫名掉了"这种最难查的 bug；
2. **软复位必须清空所有滤波器状态与运行和**（换被试/换 trial 必须调用，否则带入脏状态）；
3. `PERF_CNT` 寄存器记录上一个决策的 PL 处理周期数 —— **这就是你实测延迟的证据**，报告里直接引用。

| **P6** 打磨 | 演示脚本、降级路径、基础编程刷题 | 连续 3 次彩排零失败 |
| **P7** 加分 | FBCSP 多频带 / 通道扩展 / 在线自适应 | 精度或延迟有可量化提升 |

**算法侧的关键路径是 P1**。P1 不做透，P3/P4 上去就是一堆难以定位的精度问题。

## 7. 算法层面的风险与对策

| 风险 | 后果 | 对策 |
|---|---|---|
| 用 MNE 的 `log=True`（无归一化） | 增益一变特征就平移，部署必翻车 | 按 §2.5 自己实现归一化版本 |
| 训练端与推理端定标不一致 | 特征整体平移，精度暴跌 | 用同一个 `G`，参数文件头写明并校验 |
| CSP 分量数硬编码成 4 | 2b（3 通道）下越界或静默截断 | `n_comp = min(2m, N)` 做成可配寄存器 |
| IIR 反馈路径时序不收敛 | 上板跑不到目标频率 | 用转置直接 II 型；必要时降 Fmax 或打拍 |
| 忘了剔 1023 伪迹试次 | 精度掉 2–5 个点 | §2.3 的剔除逻辑必须有 |
| 各节增益差异导致中间节点丢精度 | SNR 上不去 | 状态位宽按最坏节点留余量；或做逐节增益重分配 |
| 滑动和超长时间运行漂移 | 极端情况下方差失真 | 整数加减本身零漂移；仍保留每 2 s 重算兜底 |
| 换被试忘记清滤波器状态 | 前一个被试的瞬态污染 | 强制软复位流程 |
| RBF 的 γ 直接搬浮点值 | 核宽度失配 | γ 必须在定点特征上重新标定 |
