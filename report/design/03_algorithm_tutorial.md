## 1. 问题定义：为什么 EEG 二分类难

被试想象左手或右手运动时，大脑感觉运动区的 **mu 节律（8–13 Hz）和 beta 节律（13–30 Hz）** 会出现能量下降（ERD），而且**左右手对应的脑区不同**——想象左手时 C4 区域（右侧）能量下降更明显，想象右手时 C3 区域（左侧）更明显。

听起来很直接，但难点在于：

| 难点 | 具体表现 |
|---|---|
| **信号极弱** | EEG 只有 ±100 µV 量级，而 ADC 的直流偏移有几百 mV —— **差 2000 倍** |
| **通道间高度相关** | C3 和 C4 记录的信号高度相似，单看任何一个通道都分不出来 |
| **信噪比低** | 眼电、肌电、工频干扰都比信号大 |
| **个体差异巨大** | 实测：B04 准确率 94.7%，B03 只有 55.9% |
| **非平稳** | 同一被试不同天、不同 session 的数据分布都不一样 |

**所以算法要解决的核心问题是：如何从 3 个高度相关的通道里，提取出一个能分开两类的、稳定的标量特征。**

---

## 2. 算法全景

```
原始 EEG (3 通道 × 626 点)
    │
    ├─ ① 去直流      一阶高通 0.5 Hz       ← 解决"直流偏移比信号大 2000 倍"
    ├─ ② 带通滤波    3 个子带 8-16/16-24/24-32 Hz ← 只要 mu/beta，丢掉肌电和工频
    │
    ├─ ③ CSP 投影    z = W^T x             ← ★ 解决"通道高度相关"
    │                 3 通道 → 3 个分量，每个分量 = 一组电极权重
    │
    ├─ ④ 对数方差    f_i = log(var(z_i)/sum_j var(z_j))  ← ★ 3×626 点 → 3 个数
    │
    └─ ⑤ SVM 判别    d = w·f + b           ← 3 维空间里的一条线
                       d > 0 → 右手，d < 0 → 左手
```

**输入 → 输出的形状变化**：`3×626 = 1878 个数` → `3 个数` → `1 个判断`。

## 3. 逐级讲解

### 3.1 为什么第一步要去直流

ADS1299 这类 ADC 的直流偏移可达 ±187.5 mV，而 EEG 只有 ±100 µV。如果不去掉，1878 个数据点里绝大部分动态范围都被那个没用的直流占掉了——相当于用一把量程 2 米的尺子去量 1 毫米的东西。

**做法**：一阶高通 `y[n] = a·(y[n-1] + x[n] - x[n-1])`，截止 0.5 Hz，`a = 0.9876 @Q1.15 = 32361`。

### 3.2 为什么用 3 个子带

- **下限 8 Hz**：低于 8 Hz 主要是眼动漂移和电极移动伪迹
- **上限 30 Hz**：肌电（EMG）主要在 30 Hz 以上，而且 mu/beta 节律的信息主要在 8–30 Hz
- **顺带的好处**：8–30 Hz 带通**天然压掉 50 Hz 工频**，不需要单独设计陷波器

**滤波器选型**（实测，单带对照方案考核点 5 Hz / 45 Hz 抑制 ≥40 dB）：

| 方案 | 规模 | 5Hz 抑制 | **群延迟@12Hz** |
|---|---|---|---|
| **Cheby2 10 阶**（单带） | **5 节** | **−42.3 dB** | **43 ms** |
| FIR 汉明 128 抽头 | 128 tap | −42.4 dB | 254 ms |

同等抑制下 **FIR 的延迟是 Cheby2 的 5.9 倍**，所以 IIR 完胜 FIR。

> ⚠️ **群延迟的算法**：`rad/Hz` 换算成秒要**除以 2π**。
> 可用 FIR 的解析值交叉验证：128 抽头的群延迟必然是 $(128-1)/2/250 = 254$ ms。

**★ 但最终配置用的是 3 个宽带子带，每带只要 2 节（4 阶巴特沃斯）**：

| 子带 | 节数 | 带中心群延迟 |
|---|---|---|
| 8–16 Hz | 2 | 54.5 ms |
| 16–24 Hz | 2 | 55.6 ms |
| 24–32 Hz | 2 | 55.9 ms |

**为什么低阶就够**：FBCSP 相邻子带**故意重叠**，不需要陡峭截止。
追求陡峭截止会让每带要 5–8 节，9 带就是 72 个 biquad——而 3 带 × 2 节只要 **6 个 biquad/通道**。

**为什么 3 带比 6/9 带更准**：实测 3 带 79.40% > 6 带 79.03% > 9 带 78.47%。
窄带（4 Hz）滤波器群延迟长达 111 ms 且噪声更多，宽带（8 Hz）反而更好且更省。

### 3.3 ★ CSP：解决"通道高度相关"

**直觉**：既然 C3 和 C4 单独看都分不出来，那就**把三个通道加权组合成一个新信号**，权重的选择标准是：

> 让第一类的方差尽量大，同时第二类的方差尽量小。

这样得到的信号 z₁ 就是"专门为区分左右手而设计的"。

**图示**（[figC5](figures/figc5_csp_filters_b01.png)）：每个滤波器就是一列权重，红=正、蓝=负。你会看到滤波器 1 在 C3/C4 上权重相反——这正是它能把左右手分开的原因。

**数学**：这是一个广义特征值问题：

```
① 每类平均协方差：  C1, C2               （每试次协方差先做迹归一化）
② 正则化：          C ← (1-α)C + α·(tr(C)/N)·I    （α 由 Ledoit-Wolf 自动估计）
③ 复合协方差：      Cc = C1 + C2
④ 白化：            P = U·D^(-1/2)·U^T,  [U,D] = eig(Cc)
⑤ 求特征向量：      [V,L] = eig(P·C1·P^T)，按特征值降序
⑥ 空间滤波器：      W = P^T·V
⑦ 取首末各 m 列：   首 m 列 = 类1方差大；末 m 列 = 类2方差大
```

**★ 一个必须注意的实现细节**：第 ⑦ 步受通道数限制。

$$n_{comp} = \min(2m,\ N)$$

本数据集只有 3 通道，所以 `m=2` 请求 4 个分量，**实际只得到 3 个**。MNE 会静默截断——如果代码里把特征维硬编码成 4，后面就会越界。

**★ 最重要的工程点：CSP 训练只在 PC 上做。**

推理时 `W` 是已知常数，只需要算一次矩阵乘法 `z = W^T x`。**特征分解不需要进 FPGA**——这正是 CSP 适合硬件化的根本原因。

### 3.4 为什么用对数方差

投影得到 z 之后，每个分量有 626 个时间点，还要压成一个数。用**方差**是因为 ERD 表现为节律能量的变化，而方差就是能量。

**为什么要取对数**：

1. 方差的分布是**右偏的**（少数试次方差很大），取对数后更接近正态，SVM 更好处理；
2. ERD 是**乘性**的（能量下降 30%），取对数后变成**加性**的（减一个常数），线性分类器才适用。

### 3.5 ★ 为什么要归一化

特征定义有两种写法，差别很大：

| 定义 | 公式 | 对信号整体缩放 |
|---|---|---|
| MNE 的 `CSP(log=True)` | `f_i = log(var(z_i))` | ❌ 缩放 a 倍 → 整体平移 `2·ln a` |
| **经典 CSP 定义** | `f_i = log(var(z_i) / sum_j var(z_j))` | ✅ **完全不变** |

**实测**（固定 W 不变，把输入整体放大 100 倍，模拟增益标定差 40 dB）：

```
MNE log(var)          特征平移 Δ = 9.210   ← 正好等于 2·ln100，完全跑偏
归一化 log(var/sum)   特征变化 Δ = 4.4e-16 ← 恒定不变
```

**归一化带来三个部署上的实质好处**：
1. PL 端**不需要精确增益标定**，可以直接在 ADC 计数域计算，省掉 µV 换算；
2. **对通道间增益差异免疫**（ADS1299 各通道增益误差被归一化吸收）；
3. 换电极、换被试时的阻抗差异**不会平移特征**。

**代价**：精度基本无差（实测 73.00% vs 72.50%），但归一化会改变特征尺度，**SVM 的 C 和 γ 必须在同一套特征上重训**。

### 3.6 SVM：在特征空间里画一条线

有了 3 维特征，每个试次就是空间里的一个点。SVM 找一个**间隔最大**的超平面把两类分开：

$$d(f) = \sum_i \alpha_i y_i K(f, sv_i) + b = w\cdot f + b$$

**为什么要用 SVM 而不是 LDA**：LDA 假设两类协方差相同且服从正态分布；EEG 特征往往不满足。SVM 只关心**边界附近的点**（支持向量），对分布假设不敏感。

**图示**（[figC3](figures/figc3_feature_space_b04.png)）：散点就是特征，虚线就是决策边界 `d = 0`。B04 的两类几乎完全分开；B01 则混在一起。

### 3.7 ★ 线性核可以折叠——这一步对 FPGA 至关重要

线性核下：

$$d(f) = \sum_i \alpha_i y_i (sv_i \cdot f) + b = \left(\sum_i \alpha_i y_i sv_i\right)\cdot f + b = w\cdot f + b$$

**实测等价性**：折叠前后的决策值最大差 `1.8e-13`（浮点舍入量级），预测标签完全一致。

**含义**：

| | 需要存的东西 | B01 实测 |
|---|---|---|
| 不折叠 | K 个支持向量 × 特征维 | 282 × 3 = 846 个数 |
| **折叠后** | **特征维个权重 + 1 个偏置** | **3 + 1 = 4 个数** |

BRAM 占用降两个数量级，硬件就是 3 个乘法器 + 加法树。

**关键观察**：第 ③ 级之后，**原始通道信息已经不可逆地混合了**。z₁ 不对应任何一个电极，它是"最能区分左右手的方向"。这就是空间滤波的本质。

## 7. 七个坑（都有实测数据支撑）

### 坑 1：训练端和推理端用了不同实现 ★最严重

我实测发现：**MNE 的 `CSP.transform()` 输出，不等于 `log(var(filters_^T · X))`**，最大差 **2.0 个对数单位**。

后果（B01，同一份数据，同一份 W）：

| 实现 | 准确率 |
|---|---|
| MNE 全流程 | 66.88% |
| MNE 的 W + 自己算特征 | 60.62% |
| 自己的 W + 自己算特征 | 60.31% |

**混用两套实现，得到的结果既不是这个也不是那个，而且没有任何报错。**

**对策**：训练端、定点仿真、PS 参考实现、PL 硬件，**必须用同一套特征定义**，并且逐级对拍。

### 坑 2：用 MNE 的 `CSP(log=True)` 当部署特征

它算的是 `log(var)`，**不含归一化**，对增益变化敏感（见 §3.5）。必须自己实现归一化版本。

### 坑 3：特征维硬编码成 `2m`

3 通道下 `m=2` 只得 3 个分量。`n_comp = min(2m, N)` 必须做成可配置。

### 坑 4：忘了剔除被标记的伪迹试次

BCI IV 2b 用事件 `1023` 标记被剔除的试次，B01 有 76 个。不剔除会掉 2–5 个百分点。

### 坑 5：以为迹归一化很关键

实测：做了 68.25%，不做 68.19%——**差 0.06 个百分点，可以忽略**。别在这个细节上纠结太久（但它确实是经典 CSP 的标准步骤，做了无害）。

### 坑 6：担心因果滤波损失精度

实测：因果滤波 vs 零相位滤波差 **0.61 个百分点**（而且因果还略好一点，在噪声范围内）。

**这其实是个好消息**：FPGA 上只能做因果滤波，而它几乎不损失精度。

### 坑 7：在时间窗上想当然

时间窗对结果影响很大（实测同一被试不同窗差 4 个百分点），而且两类会话的想象期不同（筛查会话 [2,6] s、反馈会话 [3,7.5] s），**共用合法区间只有 [3,6] s**。必须用真实数据扫一遍，不要照抄别人的窗。

## 8. 从算法到硬件：为什么这个算法适合 FPGA

| 算法特点 | 对硬件的意义 |
|---|---|
| 推理时 CSP 退化成**一次矩阵乘法** | 不需要在 FPGA 上做特征分解——这是最大的障碍，被"训练/推理分离"消掉了 |
| 线性 SVM 可**折叠**成 `w·f + b` | 只存 4 个数，硬件 = 3 乘加 |
| 滤波运算量极小 | 8 通道 × 3 带 × 2 节 biquad × 5 MAC = 240 MAC/采样点，**可时间复用到 1–2 个 DSP**（占用 0.05%） |
| 滑动窗方差可用**运行和** | 每采样点 O(1)（加新减旧），**决策更新率可达 250 Hz** |
| 归一化特征**与增益无关** | 不需要精确标定，ADC 计数域直接算 |
| 全流水、无分支 | 延迟是**常数**，无 OS 调度抖动 |

**最关键的洞察**：不要用"加速比"当卖点——这个算法在 PC 上跑一个试次只要几十微秒，FPGA 跑不赢。真正的优势是：

> **确定性延迟 + 每 4 ms 更新一次决策的连续实时性 + 通道数可扩展 + 功耗**
